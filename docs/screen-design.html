UI 要素・入力仕様
要素種類バリデーション
商品名input[type=text]必須・最大 100 文字
カテゴリselect必須
価格input[type=number]必須・1 以上・整数
在庫数input[type=number]必須・0 以上・整数
商品画像input[type=file]任意・JPEG/PNG・5MB 以下
画像プレビューimgFileReader でプレビュー表示
登録ボタンbutton送信中は非活性・ローディング表示
処理フロー（画像あり）
  1. クライアントバリデーション
  2. GET /products/upload-url（Presigned URL 取得）
  3. 取得した URL へ画像を直接 PUT（S3 へ）
  4. POST /products（imageKey を含めてリクエスト）
  5. 成功 → S09（商品管理）へ遷移
処理フロー（画像なし）
  1. クライアントバリデーション
  2. POST /products（imageKey なし）
  3. 成功 → S09 へ遷移

⚙️ エラー・ローディング共通仕様
ローディング表示
  • 一覧取得中 スケルトンカード（3×2 グリッド）
  • 詳細取得中 スケルトンレイアウト
  • ボタン送信中 ボタン内スピナー + 非活性
バリデーションエラー
  • 各入力フィールドの直下に赤字で表示
  • 送信ボタンは全バリデーションが OK になるまで非活性（または送信時にまとめて検証）
エラー種別表示場所メッセージ例
401 / 未ログイン—/login へリダイレクト
403 権限なしページ上部バナー（赤）この操作を行う権限がありません
404 見つからないページ中央商品が見つかりませんでした
409 在庫不足フォーム上部（赤）在庫が不足しています。カートを確認してください
500 サーバーエラーページ上部バナー（赤）サーバーエラーが発生しました。しばらくしてから再試行してください
ネットワークエラーページ上部バナー（赤）通信エラーが発生しました
